Probably Stolen v0.46DThe Back Room

Everything the full release ships but never shows you. I pulled this out of the game in three passes: the decompiled code, the asset files read with type trees generated from the game's own DLLs, and a dump mod running inside the live game through the official modding harness.

Each find was checked against the code, the scenes and the running game. An ID the game assembles from parts can still slip through, so treat every entry as a strong lead.

Sprites, portraits, scene layers and text are from Probably Stolen by Questing Goose Studio, extracted from a purchased copy for reference. The page font is Mx437 Tandy2K, which the game itself ships, from VileR's Ultimate Oldschool PC Font Pack (int10h.org, CC BY-SA 4.0). Raw data, scripts and the dump mod live on the datamine/probably-stolen branch of sshlich/supermarket.
