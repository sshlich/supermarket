# Item guide

What every item in the station data is, what it is for, and where it sits in the chain (where it comes from, what it goes
into). Written from `data/station/*.json` (items, recipes, machines, discs, outside, orders, upgrades), not from the game code.
Read the overview at the top of each file first: it says how that group fits the loop (scrap -> crusher/recycler ->
materials -> machines -> goods -> sold).

Four kinds exist only in the game, with no station entry:
- **Floppy disc** (2x2, 3$): a blank 3.5-inch floppy; needs a computer to read.
- **Canvas pack** (3x3, 10$): worn on your back at night, with a 4x4 inside; what fits in it comes home.
- **Printed page** (2x2, 0$): a sheet off the printer.
- **Tape gun** (2x1, 4$): dropped on a box it tapes it shut; only a knife opens it.

Caveats: `machines.md` and `discs.md` were generated by script from the data, so their wording is templated. Other files are
summaries: each item lists its main 3-5 links per direction, with "and N more" for the rest. Data oddities the writers found
(dead ends, items with no source, notes that disagree with recipes) are mentioned in the entries themselves.
