# Canonical prototype rulings

Authority: the supplied [dossier](../bazaar_mechanics_dossier.md). “Provisional” below describes the relationship to the live reference, not implementation completeness. These decisions are deterministic and covered by tests. They should change only with a version bump and reviewed fixture diffs.

| ID  | Decision and rationale                                                                                                                                                                                                                                                                                                                                                                                                   | Confidence / narrow boundary                                                                      | Evidence                                                         |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| R01 | Board/stash widths are 1/2/3, capacities max 10. Neighbors are immediate item instances in order, even across empty slots. Equal-size placement onto another item swaps them.                                                                                                                                                                                                                                            | Strong / `geometry.ts`, `run.ts` move                                                             | geometry and swap tests                                          |
| R02 | Natural tied timers resolve owner, board position, sequence; reactions use priority before position. Skills sort after item positions within an owner. Signals 5, ticks 10, reactions 20, quest rewards 25, casts 30, death 90. Actions are atomic within each cast. This makes interactions inspectable.                                                                                                                | Provisional / task comparator and phase assignments                                               | ordering golden; queue test                                      |
| R03 | Status expiration occurs before same-time readiness. Haste ×2 and Slow ×½ cancel multiplicatively. Durations add from the later of now/current expiry. Freeze prevents forced and natural use.                                                                                                                                                                                                                           | Provisional for combination/expiry; Strong for individual rates / rate and gate helpers           | rate, Freeze-expiry, forced-use tests                            |
| R04 | Charge clamps overflow; queued readiness coalesces per source. Progress is never paused or reset by empty Ammo. Reload at full charge queues a use immediately. Full Reload may waste its effect on a full item.                                                                                                                                                                                                         | **Authoritative user correction** / independent resource and timer gates                          | `ammo-ready` golden; three explicit readiness regressions        |
| R05 | One Ammo is spent at the start of each successful cast, including multicast. Crit is one clamped basis-point roll per cast, shared by Damage/Shield/Heal/Regen/Burn/Poison. Each multicast rechecks source/resources and selects targets again, 120 ms apart.                                                                                                                                                            | Provisional granularity; Strong eligible outputs / cast pipeline, `multicastInterval`             | shared-crit/multicast test, reaction golden                      |
| R06 | At each whole second: Regen (including its heal/cleanse), Poison, Burn, then storm. Owners resolve p0 then p1 within each stage. Burn every 500 ms decays by 1; Poison every second ignores Shield. Shield halves Burn with floor rounding.                                                                                                                                                                              | Strong basic status semantics; Provisional same-time order / periodic tick                        | status-order unit and reaction golden                            |
| R07 | Positive ordinary healing, including overheal and Regen, cleanses floor(10% of each current Burn/Poison stack). Lifesteal never cleanses. Flat, percentage and complete Cleanse share one handler.                                                                                                                                                                                                                       | Provisional percentage/overheal rule / `healCleansePercent`, heal/cleanse helpers                 | healing/overheal, regen and cleanse tests                        |
| R08 | Lifesteal uses actual Shield damage plus actual Health damage, excluding overkill, with basis-point scaling.                                                                                                                                                                                                                                                                                                             | Open reference detail, provisional ruling / damage handler                                        | Lifesteal test                                                   |
| R09 | Health can go below zero during a cast. Death is proposed, replacements/reactions resolve, then phase 90 commits. Simultaneous dead players draw. A revive that remains at or below zero fails to prevent death.                                                                                                                                                                                                         | Provisional / propose/commit death                                                                | Return Token test; ordering golden                               |
| R10 | Destroy disables timers and auras, bumps source generation and invalidates queued work. Repair bumps generation again and retains charge, Ammo, durations and once counters. Durations continue to expire while destroyed. Sheltered items can either be excluded by selector or selected and absorb.                                                                                                                    | Provisional repair/absorption policy / effect handlers and generation check                       | destroy-repair golden; aura and absorption tests                 |
| R11 | Flying halves new Freeze/Slow duration with floor rounding. Start/stop is idempotent. Intrinsic Flying initializes state without emitting a start transition.                                                                                                                                                                                                                                                            | Strong benefit; Provisional intrinsic-start event / Flying handler                                | Flying and status tests                                          |
| R12 | Transform preserves instance identity, size and tier; chooses a same-size non-Legendary result from the specified pool; retains a supported enchantment. It discards definition-specific mutations, added types, counters, quests, statuses and progress, and refills new Ammo. Combat transformations default to fight-only; artisan transforms persist.                                                                | Dossier recommendation plus provisional inheritance / Transform handlers                          | transform golden and scope tests                                 |
| R13 | Ordinary duplicate acquisition upgrades the oldest eligible owned instance one tier, retaining identity/mutations. A non-null incoming enchantment replaces the old one; a plain duplicate retains it. Incoming tier does not skip steps. Generated acquisitions coexist. Max-tier owned definitions disappear from shop/reward purchases.                                                                               | Strong base behavior; Provisional target/plain-enchantment policies / acquire and upgrade helpers | duplicate, skill-upgrade, max-tier tests                         |
| R14 | Buy price and sell value are independent. Payment precedes acquisition/upgrade and buy reactions. Purchase/sale counters include the current transaction before subscribers run. Sale subscribers see the outgoing source; removal precedes gold payment. Combat value cannot affect sale proceeds.                                                                                                                      | Provisional ordering / run reducer                                                                | transaction, quest and scope tests                               |
| R15 | Completing an hour publishes encounter completion, grants hour XP, then publishes hour completion. All queued levels resolve before clock advance. Levels from shop actions interrupt and then resume that shop. Day-end → advance/reset day scopes → income → day-start → hour-start → offers.                                                                                                                          | Provisional / completeHour, advance and pending continuation                                      | multi-level/hour, save and day-reset tests                       |
| R16 | Level rewards are queued individually and eligibility is recomputed at resolution. Health increases current combat health by the maximum-health delta. New runs refill combat health each fight.                                                                                                                                                                                                                         | Strong table mechanism, provisional health policy / reward queue and max-health refresh           | multi-level test; health aura and persistence tests              |
| R17 | Quest progress increments on qualifying events; completion is published before reward actions. Nonrepeatable quests stop at their threshold. Repeatable quests can reset or retain overflow. A completing event does not re-run a newly unlocked trigger.                                                                                                                                                                | Provisional / shared ability memory                                                               | Survey Kit test                                                  |
| R18 | Expressions floor divisions; zero division and unsafe integer intermediates fail. Modifier order is set/add/percent/multiply/min/max inside each layer. Cooldowns floor at 200 ms. Recursive or random auras are rejected.                                                                                                                                                                                               | Prototype policy / evaluator, validator, content rules                                            | arithmetic, modifiers and schema tests                           |
| R19 | Storm starts at 30 s and ticks each second for `min(1000, 4 + 5 × tickIndex)` damage. Rules data selects Shield bypass or ordinary Shield absorption, and timeout draw or highest current Health (equal Health draws). Defaults bypass Shield and draw at 90 s. Early requests use the next strictly future 500 ms checkpoint so the base tick/start event cannot be skipped. Configured starts must be at least 500 ms. | Open live details, provisional curve / rules and tick scheduler                                   | Cap/mitigation/timeout/early-start tests; Sand Hourglass content |
| R20 | Rival losses/draws cost `min(12, day + 1)` Prestige. One last chance sets Prestige to 1 and offers three original rewards; the next exhausted buffer ends the run. PvE losses cost no Prestige. Ten wins take precedence over other termination checks.                                                                                                                                                                  | Original balance; Strong structure / result reducer and rules                                     | complete victory/defeat, PvE loss tests                          |
| R21 | Three market categories are weighted independently, with day-local exclusion preferred and safe fallback when a category is exhausted. Rival/monster selection excludes the previous selected snapshot when alternatives exist. No wall-clock decision timer.                                                                                                                                                            | Prototype policy / encounter generator and named RNG                                              | complete run and browser flow                                    |
| R22 | Rage/Enrage, Tempo and slot states are opt-in canonical infrastructure, absent from the neutral shops. Fixture-enabled uses gain 9 Rage per occupied slot; 100 Rage clears Slow/Freeze and reduces cooldown 10% for 5 s. Tempo gains 1/s and explicit actions spend it. A matching type Note reduces cooldown 10%. Heated/Chilled are independent named states, without invented hero rules.                             | Provisional infrastructure / meter/slot verbs                                                     | `scopes-and-meters` golden                                       |
| R23 | Scope defaults follow the effect: damage/status/timers/destruction/flight are combat state; item upgrades and run purchases are persistent; modify requires an explicit scope in content. Timed modifiers expire, activation modifiers clear after the cast/standalone reaction, combat modifiers never enter saves. Persistent type/resource/Transform effects use a write-back journal.                                | Prototype policy / modifier arrays and persistence journal                                        | scope, day, save and activation tests                            |
| R24 | Depth 64, 1,800 events per timestamp, 18,000 per fight, and a task-count guard produce diagnostic errors. These are configurable limits, not normal game losses.                                                                                                                                                                                                                                                         | Open reference safeguards, prototype policy / RulesMachine guards                                 | depth-cycle and timestamp-budget tests; 10k stress               |

Original balance values deliberately differ from the reference. The initial package, shop distribution, health growth, encounter rewards and opponent strengths are a baseline for playtesting. Full behavioral fidelity remains subject to the empirical backlog.
