# README.TXT
Copy this file to a new name in this folder (without the underscore). The lines between the dashes are the label, the colour of the disc's plastic (a hex colour) and a line for the tooltip.

Every line that starts with a hash and a space begins a new file on the disc; the rest of the line is its name. Keep names short and in capitals, like an old disc's: NOTES.TXT, LOG_0412.TXT.

Files are shown exactly as written, line breaks and all, so write each paragraph on one line and break lines only where they should break (lists, tables).

# SECOND.TXT
Each file is shown as plain text, as it is written here.
