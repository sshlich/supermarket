# The First Chapter

Copy this file to a new name in this folder (without the underscore) and write. The name of the file is the book's id; the
lines between the dashes above are its title, its author, its cover colour (a hex colour) and a line for the tooltip.

Leave a blank line between paragraphs. A line that starts with a hash and a space begins a new chapter, on a new page.
Words between *asterisks* are set in italics. The game cuts the text into pages by itself.

# The Second Chapter

The book shows up in the tray under the field, customers start bringing it in, and it opens with a double-click.
