# 99. Glossary and timeline

*Continuity file. Every proper name and coined term in the SPECULATIVE corpus (files 00 to 14), alphabetical, with a
one-line definition and the files it appears in. Leading "the" is ignored in sorting. File numbers are the file prefixes
(`01` = `01-history.md`, `06a` = `06a-factions.md`, and so on). Generic item names that only appear in one item table
(a "bag of bran", "chisel set") and one-off table labels are left out; everything with a name, a place, a date or a
meaning special to the Stack is in.*

*Where the corpus disagrees with itself, the entry gives the **resolved** form (the one the continuity pass keeps, chosen
to match `00-canon-brief.md` and the majority of files) and marks the retired variant with "retired variant". The list
of fixes that brings each file in line is kept with the continuity notes, not here.*

**Fixed reference points used throughout:** the Stack has 104 floors: drowned 0–3, Sump 4–9, Mills 10–29 (player on 17),
Middle 30–59, Terraces 60–89, Crown 90–104 (the Lantern 101–104 on top). The Dark Floors are 22–26. Y0 is the founding;
~Y41 automation; Y57 the Drowning (19.III); the present is Y86. Mills labourer about 30 cr a day; a Vitabrick 3 cr;
Halden Pure at the Mills tap 1.20 cr a litre; rent on 17 is one fixed number, 125 cr a week, rising about 3 cr every month. A square is a square of the board (the starting board is 25 x 20), not a size in metres.
